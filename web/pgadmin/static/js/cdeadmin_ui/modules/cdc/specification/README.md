# Embedded CDC Designer machine contracts

These files are exact, read-only-at-runtime copies of the normative version 1.0
CDC Designer module manifest and screen contracts from the first-party module
specification package. They are bundled with the implementation so automated
tests and runtime diagnostics can verify surface, command, task, state,
accessibility, persistence and multi-window conformance without depending on an
external checkout.

The human-readable module specification and normative SVG remain authoritative
design inputs. The canonical CDC asset and live runtime state are not derived
from the SVG.
