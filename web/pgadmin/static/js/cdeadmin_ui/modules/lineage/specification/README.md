# Data Lineage embedded specification

This directory contains the production-owned machine manifest used to verify
the first-party `cdeadmin.lineage` implementation. Its authority is the
read-only CDEadmin First-Party Module Specifications package, version 1.0.

The runtime never reads the external specification package. Provider support
is unknown until a provider registers and evidences the complete Lineage
adapter contract. OpenLineage content is version-preserved and DDN remains a
non-authoritative projection.
